# Demonstration Script

1. Run `python run_validation.py` and show all three circuits accepted.
2. Launch `python run_game.py`; show the Main Menu and controls.
3. Open Track Explorer. Show the graph, ordered checkpoints, shortcuts, BFS/DFS information, and Dijkstra/A* route metrics.
4. Show the four route-cost presets and explain why their scalar costs can choose different routes.
5. Start a race. Point out fuel, nitro, checkpoint progression, deterministic opponents, and the event feed.
6. Wait for the scheduled road blockage and show route recalculation without restarting.
7. Open Algorithm Lab and show counters from the shared route-planner implementation.
8. Run `python run_championship.py` and show standings/top-3 output.
9. Run `python run_experiments.py` and show one raw CSV and one chart.
10. Finish with `build_submission.ps1` and show the manifest/ZIP contents.
